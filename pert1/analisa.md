# XAMPP VS DOCKER

- XAMPP: Semua software dijalankan langsung di komputer (localhost). Tidak ada isolasi antar proyek.
- DOCKER: Setiap aplikasi jalan dalam container terpisah.

-----

## XAMPP 
adalah paket perangkat lunak yang digunakan untuk mengembangkan aplikasi web secara lokal. XAMPP menyediakan semua yang diperlukan untuk menjalankan aplikasi berbasis web, seperti:

- Apache: Web server untuk menyajikan konten.
- MySQL/MariaDB: Database untuk menyimpan data aplikasi.
- Bahasa pemrograman untuk menjalankan logika aplikasi web.
- Perl: Bahasa pemrograman tambahan yang juga didukung.

----- 

## Keunggulan XAMPP:

- Instalasi Mudah: XAMPP sangat mudah untuk diinstal dan digunakan oleh pengembang yang ingin menjalankan aplikasi web lokal tanpa banyak konfigurasi.
- Komprehensif: Sudah menyertakan Apache, MySQL, PHP, dan Perl, jadi sangat cocok untuk pengembangan aplikasi berbasis PHP.
- Penggunaan Lokal: Biasanya digunakan untuk pengembangan aplikasi secara lokal di komputer sebelum di-deploy ke server.

-----

## Docker
Docker adalah platform yang digunakan untuk mengembangkan, mengirimkan, dan menjalankan aplikasi dalam bentuk kontainer. Kontainer ini memungkinkan aplikasi berjalan dengan cara yang konsisten di berbagai lingkungan tanpa khawatir tentang perbedaan konfigurasi sistem operasi.

-----

## Keunggulan Docker:

- Portabilitas: Aplikasi dalam kontainer Docker bisa dijalankan di berbagai lingkungan tanpa khawatir tentang kompatibilitas.
- Isolasi: Setiap kontainer bekerja secara terpisah, sehingga aplikasi tidak saling mempengaruhi.
- Skalabilitas dan Manajemen: Docker mendukung penggunaan kontainer dalam skala besar, sangat berguna dalam pengembangan dan produksi aplikasi berbasis microservices.
