# BOOSTRAP 

Bootstrap adalah framework front-end yang digunakan untuk mempermudah pengembangan antarmuka web. Framework ini menyediakan berbagai komponen siap pakai seperti grid system, tombol, form, navigasi, dan lainnya, yang dirancang agar responsif dan mudah digunakan. Bootstrap menggunakan HTML, CSS, dan JavaScript, sehingga sangat membantu dalam membuat desain web yang modern dan kompatibel dengan berbagai perangkat.

# Bootstrap sangat populer karena

- Responsif: Menggunakan grid system untuk membuat desain yang fleksibel dan dapat menyesuaikan dengan berbagai ukuran layar.
- Komponen Siap Pakai: Menyediakan elemen UI seperti navbar, modal, carousel, dan lainnya.
- Kustomisasi Mudah: Dapat disesuaikan dengan kebutuhan proyek.
Dokumentasi Lengkap: Memiliki dokumentasi yang jelas dan mudah dipahami.

# How to Installation Bootstrap?

## Menggunakan CDN

Cukup copy-paste link CSS dan JS dari server Bootstrap langsung ke file HTML.

```html
<!-- Bootstrap CSS via CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap JS via CDN -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
```

## Kelebihan pakai CDN:

- Cepat dan Praktis: Gak perlu download file apapun.
- Selalu update: Biasanya langsung dapat versi terbaru.
- Ringan: Karena file diambil dari server cepat dan besar.

## Kekurangan pakai CDN:

- Butuh internet: Kalau internet down atau lambat, Bootstrap bisa gagal load.
- Kurang fleksibel: Susah kalau mau ubah isi Bootstrap secara langsung.
